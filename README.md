A deterministic Python 3.13 program that prints its AI agent's Tinder bio: name, age, headline, bio lines, dealbreakers, red flags, green flags and a pickup line.

## Run it

```sh
python3 main.py
```

Standard library only, no network, no randomness — two runs print identical bytes.
